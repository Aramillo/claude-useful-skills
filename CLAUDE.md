# CLAUDE.md

Este repo es una **biblioteca de referencias** a skills de Claude Code. De las skills de terceros solo se guarda la URL, para qué sirve y el comando de instalación, todo en `EXTERNAS.md`. Las carpetas de categorías (`dev/`, `seguridad/`, `entrevistas/`) son solo para skills propias.

## Cuando pida una skill

Ejemplos: "instala la skill de seguridad", "busca una skill para X".

1. Lee `EXTERNAS.md` y busca la referencia que encaje (por nombre, categoría o columna "Para qué la uso").
   - Si no hay ninguna, dímelo y propón buscar una (por ejemplo con la skill `find-skills`). No la registres sin mi visto bueno.
2. Descarga el `SKILL.md` del repo de origen y muéstramelo completo para que lo revise. Señala lo que merezca atención: comandos que ejecuta, scripts incluidos, accesos a red, permisos que pide.
3. Espera mi confirmación explícita. Sin ella no se instala nada.
4. Solo después de confirmar, ejecuta el comando de la columna "Instalación" tal cual está registrado.

## Reglas

- **Nunca copies el contenido de una skill de terceros dentro de este repo** (ni el `SKILL.md`, ni scripts, ni fragmentos). Si hace falta revisarlo, se muestra en la conversación o se descarga fuera del repo (carpeta temporal).
- Al registrar una skill nueva en `EXTERNAS.md`, rellena todas las columnas y usa la fecha del día (AAAA-MM-DD) como fecha de registro.
- Nada de secretos en ningún archivo del repo.
